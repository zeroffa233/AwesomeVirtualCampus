# 虚拟校园 (VCampus) 系统项目报告

## 1. 项目概述

“虚拟校园 (VCampus)”项目旨在构建一个功能全面的综合性平台，以数字化方式模拟和管理校园内的各项核心业务。该系统致力于为学生、教职员工及系统管理员提供一个统一、高效的线上交互环境，从而提升校园管理的智能化水平与用户体验。

项目的核心目标是整合传统校园中分散的线下服务，将其迁移至线上，涵盖用户身份认证与管理、学生学籍信息维护、在线课程选修、数字图书馆资源访问、虚拟校园商店购物、线上银行金融服务，以及一个基于大语言模型（LLM）的智能问答界面。通过这一系列功能的集成，VCampus系统旨在构建一个便捷、互联的虚拟学习与生活生态。

## 2. 系统架构

VCampus系统采用经典的客户端/服务器（C/S）架构模式，确保了业务逻辑与用户界面的清晰分离。客户端作为桌面应用程序，为用户提供直观的图形交互界面；服务器端则负责处理所有核心业务逻辑、数据存储与管理。

在通信层面，客户端与服务器之间通过Java Socket技术进行数据交互，实现了高效、可靠的网络连接。为应对高并发场景，特别是选课高峰期可能出现的请求洪流，服务器端引入了多线程处理机制，确保系统能够稳定、及时地响应大量并发用户请求，避免性能瓶颈。

系统内部设计遵循严格的分层架构原则，将功能模块划分为表示层、业务逻辑层和数据访问层，各层职责明确，降低了模块间的耦合度。同时，在客户端应用开发中，我们采纳了模型-视图-控制器（MVC）设计模式，进一步实现了业务逻辑与用户界面的有效解耦，提升了代码的可维护性和可扩展性。

## 3. 核心功能模块

VCampus系统涵盖了以下主要功能模块：

*   **用户管理模块**：作为系统的基石，提供用户注册、登录、登出功能，并基于角色（学生、教师、管理员）进行精细化的权限控制，确保不同用户只能访问其被授权的功能。
*   **学生学籍管理模块**：主要面向管理员，支持对学生基本信息的录入、修改、删除及查询操作，并提供学生列表视图，便于统一管理。
*   **在线选课系统**：为学生提供便捷的在线选课服务。学生可浏览课程信息，在规定时间内进行课程的选修与退选，并随时查询个人课表。
*   **数字图书馆模块**：模拟真实图书馆的运作，用户可按书名、作者等条件检索馆藏图书，并模拟借阅与归还流程。
*   **校园商店与银行模块**：构建虚拟经济生态。校园商店允许用户浏览商品并使用虚拟货币进行购买；线上银行则提供虚拟货币的存取款、转账等基础金融服务。
*   **LLM智能聊天界面**：集成先进的大语言模型技术，为用户提供智能问答服务，解答校园相关疑问，提升信息获取的便捷性。

## 4. 非功能性需求

为确保VCampus系统的高质量运行，我们对以下非功能性需求给予了高度关注：

*   **性能**：系统需具备良好的响应速度，尤其在高并发场景下，服务器端的多线程机制应能有效处理请求，避免系统出现延迟或无响应。
*   **兼容性**：后端逻辑基于Java语言，兼容JDK 17。数据库支持MySQL 8.4.6 LTS，并确保SQL语句的通用性，以适应潜在的数据库迁移。
*   **可靠性与健壮性**：客户端与服务器间的Socket通信建立了完善的异常处理机制，能够有效应对网络中断、超时等常见问题，保障系统稳定运行。
*   **安全性**：用户密码等敏感数据在数据库中以非明文形式存储。客户端与服务器之间的数据传输严格遵循序列化规范，确保数据完整性与一致性。
*   **代码规范与可维护性**：项目开发严格遵循Google Java Style Guide等编码规范，并为关键类和方法提供详尽的JavaDoc注释。分层设计原则的贯彻，确保了代码结构清晰、易于理解和后续维护。

## 5. 技术选型

本项目在技术栈的选择上，综合考量了成熟度、社区支持、性能表现及开发效率等因素：

*   **核心开发语言：Java**
    *   Java作为一门成熟、稳定且跨平台的语言，为构建大型企业级应用提供了坚实基础。
*   **Java Development Kit (JDK) 17**
    *   选择JDK 17作为核心开发环境，因其是长期支持（LTS）版本，提供了多年的稳定更新与安全保障。该版本在语言特性、运行时性能和安全性方面均有显著提升，为系统的高并发处理和长期稳定运行提供了有力支撑。
*   **数据库管理系统：MySQL 8.4.6 LTS**
    *   MySQL 8.4.6 LTS版本以其对ACID事务的完整支持、丰富的查询功能以及强大的安全机制而入选，非常适合对数据一致性和完整性要求较高的校园管理系统。
*   **图形用户界面 (GUI) 框架：JavaFX**
    *   JavaFX是一个现代、跨平台的UI框架，提供了丰富的可视化组件和灵活的布局控制（FXML），支持CSS样式定制，能够构建响应迅速、视觉效果优良的桌面应用程序。其设计与逻辑分离的特性，也完美契合了项目的MVC设计理念。
*   **项目构建与依赖管理：Apache Maven**
    *   Maven作为业界标准的项目管理工具，自动化了项目的编译、测试、打包和部署流程。其规范的目录结构、统一的依赖管理机制以及强大的插件生态系统，极大地提升了项目的可维护性与团队协作效率。
*   **集成开发环境 (IDE)：IntelliJ IDEA**
    *   IntelliJ IDEA以其智能代码辅助、强大的重构功能、深度集成的版本控制系统以及对Maven的良好支持，成为本项目开发的首选IDE，显著加速了开发流程并保障了代码质量。

## 6. 项目设计与开发实践

在VCampus项目的整个生命周期中，我们始终秉持软件工程的最佳实践，以确保项目的高质量交付与可持续发展：

*   **分层设计与模块化**：系统严格遵循分层架构，将复杂功能拆解为独立、内聚的模块，各层之间通过清晰定义的接口进行通信，有效降低了系统复杂度，提升了可维护性。
*   **MVC模式应用**：客户端UI开发中，全面应用MVC模式，实现了数据模型、视图展示和控制逻辑的有效分离，使得UI层面的修改不会轻易影响到底层业务逻辑，增强了代码的灵活性。
*   **代码规范与质量**：团队成员严格遵循Google Java Style Guide进行编码，确保了代码风格的统一性与可读性。同时，为关键代码编写了详尽的JavaDoc注释，便于团队成员理解代码意图，加速新成员的融入。
*   **版本控制与协作**：项目采用Git进行版本控制，通过规范的分支管理策略，保障了团队成员在并行开发过程中的代码协同与冲突解决效率。
*   **持续集成与测试**：虽然报告中未详细展开，但在实际开发中，我们注重单元测试和集成测试，确保每个模块的功能正确性，并通过自动化测试流程，尽早发现并修复潜在问题。

本报告旨在全面阐述VCampus项目的设计理念、技术实现与实践方法，为项目的进一步开发、维护与演进提供坚实的基础。
